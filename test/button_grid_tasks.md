# Button Grid Task List - Large Primary

Target: Create a grid of example buttons in Figma for the **Large (Prominent)** size, **Primary** style.

**Instructions:**
*   All buttons should use **Auto-layout**.
*   All buttons should **"Hug Content"** for their width.
*   **Reference:** Use this [Primary, Icon-Only, Enabled Button](https://www.figma.com/design/mmJrW2IV06fyao9tJlZcDm/Alpha-v1?node-id=20482-9097&t=q97YGcfFHsF9nRj2-4) as a base guide.
